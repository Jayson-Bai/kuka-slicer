# 挤出量补偿器

`extrusion_compensator` 是独立的路径后处理包：它配对读取同一任务的平面
NPZ 与曲面映射后的 NPZ，并直接替换已有的 `layer_XXXX_R_E` / `layer_XXXX_F_E`
累计 E 数组。

对每个正挤出段，使用：

`ΔE_curve = ΔE_flat × (曲面三维段长 / 平面三维段长)`

路径键、数组形状、NaN 填充、XY、逻辑层号、路径与点的顺序均保持不变；没有
`_E` 的材料也不会被虚构出 E。零或负的 E 增量（例如回抽语义）原样保留。

这是第一阶段的弧长补偿，不包含喷嘴姿态、层间间隙或条带横截面积的体积模型。
