# 曲面打印姿态偏移与树脂沉积问题交接

版本：2026-09-19
适用项目：`F:\CodeX_ws\kuka_slicer` 及离线 Core 导出链路

## 1. 问题摘要

实际打印曲面后观察到：

- 从曲率开始出现的层起，树脂外轮廓沿当前曲面法向投影到打印平面的 X/Y 分量方向，逐渐向零件内部偏移。
- 早期层约 1.5 mm，后续约 2 mm；偏移随层/曲率增大。
- 内部蜂窝树脂路径也有同样特征。中心处相邻两条树脂路径分别向各自法向投影方向分开，产生明显缝隙。
- 纤维路径相对准确，问题主要集中在树脂沉积。
- 平面或低曲率区域不明显，曲面姿态变化后才明显。

用户已确认：

- NPZ 中 XYZ 表示 TCP 位置。
- KUKA 中 Tool 已正确设置。
- 树脂 TCP 定义为喷嘴圆形出料平面的圆心，而不是沿喷嘴轴线延长后的点。
- 更认可“树脂喷嘴压入曲面不足/有效法向间隙过大”这一方向。

当前结论不是“已证明 TCP 错误”，而是：优先验证树脂沉积几何/法向距离偏置；不要先在切片器里加入固定 XY 补偿。

## 2. 几何解释

设规划路径点为 `p`，曲面单位法向为 `n=(nx,ny,nz)`，实际树脂沉积中心相对规划点有法向偏置 `d`：

```text
p_actual = p + d * n
Δx = d * nx
Δy = d * ny
```

若偏移方向始终接近曲面法向的 XY 投影，最直接的解释是法向距离偏置，而不是普通全局 XY 平移。中心两条蜂窝路径的法向投影方向相反时，两条路径会分别向外分开。

必须区分：

1. TCP：喷嘴圆形出料面圆心（用户定义的 KUKA Tool TCP）。
2. 喷嘴实际轴线：出料圆面法向；TCP 点正确不代表轴线方向正确。
3. 树脂实际沉积中心：固化后树脂道截面中心。
4. 曲面接触中心：树脂与曲面实际接触区域的中心。

层高必须考虑，但世界 Z 层高、曲面法向层间距和树脂截面中心高度不是同一个量。

### 3.1 离散直线连接误差

对树脂打印段按层和 `path_id` 分组，使用连续相邻有效点计算：

- 连续点间距约 `0.04–0.048 mm`。
- 第 4 层弦高误差 99% 约 `0.00080 mm`，最大约 `0.00550 mm`。
- 第 5 层弦高误差 99% 约 `0.00072 mm`，最大约 `0.00526 mm`。
- 第 4 层 XY 中点偏差 99% 约 `0.0032 mm`，最大约 `0.0212 mm`。
- 第 5 层 XY 中点偏差 99% 约 `0.0029 mm`，最大约 `0.0203 mm`。

结论：最终 NPZ 点密度足够高，离散点之间按直线连接的理论误差约 `0.001–0.02 mm`，远小于实物的 `1.5–2 mm`，不是主要原因。

### 3.2 姿态倾角

按 KUKA A(Z)-B(Y)-C(X) 约定，将树脂 ABC 换算为工具轴相对世界 Z 的倾角：

| 层 | 倾角中位数 | 最大值 |
|---:|---:|---:|
| 1 | 0° | 0° |
| 2 | 0.34° | 0.70° |
| 3 | 1.22° | 2.53° |
| 4 | 2.41° | 5.11° |
| 5 | 3.79° | 8.05° |
| 6 | 5.09° | 10.94° |
| 7 | 6.22° | 13.42° |
| 8 | 6.96° | 15.14° |
| 9/10 | 7.27° | 15.79° |

若偏移完全由法向距离 `d` 引起：`|ΔXY| = d * sin(倾角)`。单边 1 mm 偏移在 5.1°、8.0°、15.8° 时分别需要约 11.2 mm、7.2 mm、3.7 mm 的等效法向距离。由此可见：方向符合，但不能仅用 0.25–0.5 mm 层高解释 1.5–2 mm；还要考虑姿态误差、工具几何、接触/铺展和局部测量位置。

### 3.3 挤出量证据

当前树脂计算默认：

```text
规划宽度 = 2.0 mm
层高 = 0.5 mm
挤出倍率 = 1.0
线材直径 = 1.75 mm
理论截面积 = 2.0 * 0.5 = 1.0 mm²
理论 E/mm ≈ 0.416
```

该 NPZ 树脂连续打印段的 `ΔE/Δ路径长度` 中位数约 `0.395`，比理论值低约 5%。这支持“可能有轻微欠挤出”，但不支持“挤出量不足几倍”。欠挤出通常先造成树脂道变窄和边缘收缩，不会单独让中心线偏移 1.5–2 mm。

## 4. 因素排序

### 高优先级

1. 树脂喷嘴出料面到曲面的有效法向间隙过大（压入不足）。
2. 树脂实际沉积中心相对 TCP/规划曲面的法向距离偏置。
3. 树脂喷嘴轴线相对 Tool 方向存在角度误差。
4. 现场使用的树脂 `$TOOL` 或换头后映射与标定不一致。
5. 树脂挤出压力、铺展和曲面接触改变了沉积中心。

### 中优先级

6. 曲面法向映射、姿态解释或局部姿态平滑存在树脂专属问题。
7. 层间距使用世界 Z 而不是局部曲面法向距离。
8. 喷嘴受力、机械挠曲或树脂黏度随姿态变化。

### 低优先级/已基本排除

9. 打印平面原点或全局 XY 固定偏移：不符合沿法向投影、曲率增大后出现、纤维相对准确的特征。
10. NPZ 相邻点直线连接误差：已由 `0.001–0.02 mm` 量化排除为主因。

## 5. 应测量的参数

在平面和曲面截面上分别测量：

```text
h_layer  = 相邻树脂层沿局部曲面法向的实际间距
w_bead   = 固化后树脂道宽度
h_bead   = 固化后树脂截面高度
A_actual = 固化后树脂截面真实面积
```

矩形近似时 `A_actual ≈ w_bead * h_bead`；优先使用显微截面真实面积。E/mm 应由实际截面积反推，而不是仅由“2 mm 喷嘴直径”决定。2 mm 是几何参考，不自动意味着要增加 E。

如果只考虑半层高 `0.25 mm` 的法向中心偏置，在最大倾角 15.8° 时 XY 投影约 `0.07 mm`；完整 `0.5 mm` 也约 `0.14 mm`。因此当前 1.5–2 mm 现象不能仅归因于层高。

## 6. 推荐实测方案

### 6.1 树脂 Tool 干运行固定点测试

1. 切换到树脂 Tool。
2. 保持 TCP XYZ 在空间同一点。
3. 只改变实际打印中使用的 ABC（0°、约 5°、10°、15°）。
4. 用激光点、硬质针尖、可擦除笔或千分表记录出料面圆心。
5. 对纤维 Tool 做同样测试。

出料面圆心移动，说明 TCP 位置/Tool 几何/现场 Tool 选择有问题；圆心稳定但轴线方向不对，说明 Tool 方向有问题；干运行准确而挤出后才偏，重点查间隙、压力、铺展和材料接触。

### 6.2 平面单线截面标定

在平面基板上只打印一条树脂线，保持姿态固定，测试当前间隙、`+0.2 mm`、`+0.5 mm`、`-0.2 mm`。测量宽度、截面高度、截面中心、单位长度 E，建立“间隙—宽度—中心—E/mm”关系。

### 6.3 曲面三倾角单线测试

在约 5°、10°、15° 的已知法向位置关闭复杂蜂窝，只打印单条树脂线。测理论路径到树脂截面中心的 XY 偏移 `s`，计算：

```text
d_fit = s / sin(倾角)
```

`d_fit` 稳定说明固定法向距离偏置；随速度/方向变化说明压力、拖拽或流变参与；方向随法向翻转说明沉积几何问题；方向固定在世界坐标则优先查 Tool/Base/机械误差。

### 6.4 挤出倍率矩阵

在同一曲面局部、同一姿态和路径上，仅改变倍率 `0.8、1.0、1.1、1.2`，保持速度、加速度、TCP 和间隙不变。宽度变化但中心不变，说明 E 不是主要位置误差；宽度和中心同时变化，说明挤出压力/铺展与间隙耦合；各倍率中心都同样偏，优先修正 Tool/间隙。

### 6.5 树脂/纤维同点对照

在相同曲面、姿态和层位置分别打印单条树脂线与纤维线；记录实际 KUKA `$TOOL` 编号和上位机 tool ID 映射。

## 7. 喷嘴轴线标定

用户的 TCP 是出料圆面圆心，因此还需单独标定轴线：在圆面确定圆心 `C`，在圆周取两个不共线点 `X/Y`，计算 `n = normalize((X-C) × (Y-C))`，按实际出料方向选择正负，并使用 KUKA Tool 方向标定流程写入。之后做固定 TCP 点、多姿态旋转测试，确认圆心不漂移、轴线按预期旋转。

## 9. 下一位 agent 的工作顺序

1. 读取本文件并确认指定 NPZ SHA256。
2. 先采集实际树脂 Tool 编号、树脂/纤维 Tool 对照、固定 TCP 多姿态点位、5°/10°/15° 单线结果。
3. 由截面照片或测量表计算 `w_bead`、`h_bead`、`A_actual`、`d_fit`。
4. 若是固定法向距离偏置，设计沿局部工具/曲面法向的补偿；不要使用固定世界 XY 补偿。
5. 若是 E/mm，按实际截面积校准 `core_resin_e_override` 或倍率，并复测中心位置，避免用过挤出“填缝”。
6. 若是 Tool 方向/位置，优先修正 KUKA Tool 和现场 tool 映射，再重新导出/注入 NPZ。

## 10. 禁止直接采取的做法

- 不要给所有树脂 XY 直接加固定 `+1.5/+2.0 mm`。
- 不要只因喷嘴直径 2 mm 就大幅增加 E/mm。
- 不要把树脂和纤维共用的公共坐标错误当作唯一解释。
- 不要把 NPZ 相邻点直线误差当作 1.5–2 mm 偏移的主因。
- 没有记录实际 Tool、速度、间隙和局部倾角前，不要比较不同样件并下结论。
