# 渐变曲率蜂窝曲面打印工作流

## 1. 目的与最终形态

本文档定义当前项目从平面蜂窝 STL 到渐变双正弦曲面沉积的完整方案。

目标不是在一个已经成型的曲面上再覆盖蜂窝，而是让蜂窝结构本身从平面逐步过渡到曲面：

```text
平面蜂窝底部
    ↓
轻微曲率
    ↓
中等曲率
    ↓
接近最终曲率
    ↓
完整双正弦曲面蜂窝
```

最终几何约定：

- STL 决定 XY 投影边界、蜂窝路径拓扑和孔洞布局；
- 曲面参数决定各沉积层的 Z 高度，不由 STL 顶部原始 Z 形状直接决定；
- 蜂窝拓扑在所有沉积层中保持一致，不能随着曲面发生 XY 拉伸、剪切或错位；
- 曲率只通过 Z 方向渐变实现；
- 顶部仍然保留开放的蜂窝孔洞，不生成连续实心顶盖；
- 外轮廓采用连续闭合的边界路径，侧面不能出现内部蜂窝孔洞投影、悬空边或架空层；
- 边界不强制裁成严格矩形，可以沿完整六边形单元的边和角自然收边；
- 相邻沉积层必须直接接触或轻微搭接，不能出现层间空隙。

这里的“曲面”是蜂窝壁上缘形成的曲面包络，而不是一张覆盖蜂窝孔洞的连续薄膜。

## 2. 当前切片器基线

当前仓库的主要数据流是：

```text
STL / 外部路径输入
        ↓
切片内核（Prusa、legacy 或 PySLM）
        ↓
ExternalSourceJob
        ↓
external_layer_paths_v1 NPZ
        ↓
下游 Core：平滑、采样、动作处理、机器人输出
```

当前代码状态需要明确记录：

1. `SliceConfig` 已有 `curve_mode`、`curve_amplitude` 和 `curve_period` 参数。
2. legacy 路径已经存在单轴正弦 Z 投影逻辑，但它不是最终需要的双正弦曲面方案。
3. 当前 `kuka_slicer/prusa_backend.py` 明确拒绝非平面模式：Prusa 后端目前只接受 `curve_mode="flat"`。
4. Prusa 原生桥负责 STL 切片、轮廓、填充、路径顺序、避障空走和基础累计 E。
5. 当前外部 NPZ 已支持每个 XYZ 点对应的累计 E，格式为 `layer_0000_R_E` 等伴随数组。
6. 现有纤维 JSON 是 XY 路径模板，不是曲面参数文件，也不应直接加入 Z、E、A/B/C 或 Core 动作。

因此，第一版落地方案应采用：

```text
Prusa 平面切片
    ↓
曲面路径映射器（新增）
    ↓
E 重新分配与可打印性检查（新增）
    ↓
保持现有 NPZ / JSON 约定输出
```

这样可以先验证曲面沉积逻辑，不需要马上改写 Prusa 的完整路径规划器。

## 3. 输入文件与职责

### 3.1 STL：几何拓扑参考

STL 在曲面模式下承担以下职责：

- 提供打印区域的 XY 投影；
- 提供蜂窝孔洞和蜂窝壁的拓扑；
- 提供外轮廓和内部边界；
- 提供平面基准层和底部结构参考；
- 提供路径数量、顺序和需要保留的材料区域。

STL 中原本的顶部 Z 高度不再直接决定最终打印顶部。曲面模式下，最终 Z 由曲面参数和层进度共同决定。

建议 STL 的几何边界满足：

- 外边界沿完整蜂窝单元或闭合边界路径收边；
- 不把蜂窝网格硬裁成会产生半个六边形的矩形框；
- 内部蜂窝孔洞边界闭合；
- 底部若要保留平面蜂窝，应保证底部路径在第一阶段为平面。

### 3.2 现有纤维 JSON：保持不变

现有纤维 JSON 继续只提供与打印平面相同坐标系下的 XY 路径模板，例如：

```json
[
  [[10.0, 20.0], [11.0, 20.5], [12.0, 21.0]],
  [[30.0, 15.0], [31.0, 16.0]]
]
```

它不负责提供：

- 曲面 Z；
- 层号；
- 机器人姿态；
- 累计 E；
- CUT、等待、回抽、复位等 Core 动作。

曲面映射应作用于统一的沉积路径层，而不是修改纤维 JSON 的格式。

### 3.3 新增曲面参数文件：`graded_surface_v1`

建议新增独立的曲面参数 JSON。第一版先支持参数化双正弦曲面，不要求 Rhino 导出完整网格。

```json
{
  "format": "graded_surface_v1",
  "units": "mm",
  "coordinate_system": {
    "plane": "XY",
    "build_axis": "Z",
    "origin": "stl_xy_min"
  },
  "domain": {
    "mode": "stl_projection",
    "boundary": "stl_outer_contour",
    "edge_policy": "closed_perimeter"
  },
  "surface": {
    "type": "double_sine_product",
    "amplitude_mm": 0.8,
    "wavelength_x_mm": 40.0,
    "wavelength_y_mm": 50.0,
    "phase_x_rad": 0.0,
    "phase_y_rad": 0.0,
    "z_reference_mm": 0.0
  },
  "progression": {
    "mode": "height",
    "transition": "smoothstep",
    "flat_fraction": 0.20,
    "stage_marks": [
      {"name": "flat", "alpha": 0.00},
      {"name": "slight", "alpha": 0.20},
      {"name": "medium", "alpha": 0.45},
      {"name": "near_final", "alpha": 0.75},
      {"name": "final", "alpha": 1.00}
    ]
  },
  "printability": {
    "max_slope": 0.25,
    "max_layer_delta_mm": 0.20,
    "min_support_overlap_mm": 0.10,
    "max_volumetric_flow_mm3_s": 8.0,
    "min_opening_mm": 2.0
  }
}
```

曲面高度函数定义为：

\[
H(x,y)=A\sin\left(\frac{2\pi x}{\lambda_x}+\phi_x\right)
       \sin\left(\frac{2\pi y}{\lambda_y}+\phi_y\right)
\]

其中 `A`、`wavelength_x`、`wavelength_y` 和相位均以毫米或弧度表示。

## 4. 曲面边界与坐标映射

### 4.1 曲面域必须服从 STL 投影

曲面不能单独使用一个与 STL 尺寸不同的矩形域。正确做法是：

1. 将 STL 投影到 XY 平面；
2. 读取 STL 的外轮廓和内部孔洞；
3. 将曲面参数映射到该投影域；
4. 对超出 STL 域的曲面点直接裁剪或拒绝；
5. 对外边界路径使用闭合边界策略；
6. 不为了保持方形外框而切断完整六边形单元。

### 4.2 蜂窝拓扑不能随曲面变形

对于每个路径点：

- `x`、`y` 保持原始 STL/Prusa 路径坐标；
- 只计算新的 `z`；
- 同一蜂窝网格的所有层使用同一组 XY 点和边连接关系；
- 外边界使用同一套闭合边界路径；
- 禁止按高度重新生成一套不同的蜂窝网格。

这一步是避免六边形失真、边界错位和层间架空的关键。

## 5. 渐变曲率沉积映射

对 Prusa 的平面沉积点 `p=(x,y,z_flat)`，第 `k` 层的目标高度为：

\[
z_k(x,y)=z_{flat,k}+\alpha_k H(x,y)
\]

其中 `alpha_k` 由层索引或实际 Z 高度确定，并且应平滑变化：

```text
底部平面层：        alpha = 0.00
轻微曲率阶段：      alpha ≈ 0.20
中等曲率阶段：      alpha ≈ 0.45
接近最终阶段：      alpha ≈ 0.75
完整曲面阶段：      alpha = 1.00
```

`alpha` 不应在两个阶段之间突然跳变，推荐使用 `smoothstep` 或单调 C2 插值。

推荐的层分配方式：

1. 底部保留一段平面蜂窝层，保证首层附着和基准稳定；
2. 在过渡层中逐渐提高 `alpha`；
3. 曲率增量由相邻层共同承担，不能把最终高度一次性放到最后一层；
4. 同一蜂窝路径的边界点和内部点都必须执行相同的曲面映射；
5. 外边界不得因为曲面映射而向外悬空。

## 6. Prusa 后端之后的新增处理器

### 6.1 推荐模块划分

建议新增一个项目模块，例如：

```text
kuka_slicer/surface_map.py
```

该模块至少包含：

- 曲面 JSON 读取和版本校验；
- STL XY 域校验；
- `H(x,y)` 计算；
- `alpha(layer_index, z)` 计算；
- 路径重采样；
- XYZ 曲面映射；
- 三维弧长计算；
- E 重新分配；
- 层间支撑和边界检查。

推荐调用位置：

```text
slice_mesh_to_job_with_prusa(...)
        ↓
ExternalSourceJob
        ↓
apply_surface_map(job, surface_config, mesh_projection)
        ↓
validate_curved_job(job, surface_config)
        ↓
write_external_source_npz(job, output_npz)
```

### 6.2 路径点处理顺序

曲面后处理不应只修改路径的首尾点。每条沉积路径都应按以下顺序处理：

1. 读取原始 XYZ 路径和原始累计 E；
2. 按 XY 或三维弧长重新采样，保证曲面波形不会被稀疏点列丢失；
3. 对每个采样点计算曲面 Z；
4. 检查相邻点的 `dz`、坡度和曲率；
5. 保持路径闭合状态、路径顺序和材料角色；
6. 重新计算该路径的累计 E；
7. 对空走路径使用安全高度，不把空走误当成沉积曲面路径；
8. 保留 Prusa 原有 motion order 和 travel 关系。

第一版建议喷嘴方向保持竖直，只修改 XYZ；等 XYZ 曲面沉积稳定后，再考虑按照曲面法向生成 A/B/C 姿态。

## 7. 挤出量 E 的分配原则

曲面高度由 Z 路径决定，不能只靠增大挤出量制造曲率。E 的作用是补偿三维路径长度和实际丝材体积。

对相邻曲面点 `p_j` 和 `p_{j+1}`：

\[
ds_{3D}=\|p_{j+1}-p_j\|
\]

若丝材截面积为：

\[
A_f=\frac{\pi d_f^2}{4}
\]

目标沉积截面积近似为：

\[
A_b=w_{eff}h_{eff}
\]

则本段挤出量增量为：

\[
\Delta E_j=\frac{A_b\,ds_{3D}}{A_f}\,s_{flow}
\]

实现上可以先使用 Prusa 的平面累计 E，再按三维和平面弧长比例修正：

\[
\Delta E_{curved}
\approx
\Delta E_{prusa}\frac{ds_{3D}}{ds_{XY}}
\]

之后再加入局部层厚、有效线宽、速度和流量限制。

必须遵守：

- E 是每条路径每个点的单调累计值；
- `_E` 数组与对应 XYZ 路径点数完全一致；
- 不能用 E 的变化替代 Z 高度变化；
- 不能在有空走的路径上累计沉积 E；
- E 修正后仍要检查最大体积流量；
- 旧的消费者没有 `_E` 时仍可回退到原有 `e_per_mm` 逻辑。

## 8. 现有输出格式保持不变

曲面功能不应破坏当前纤维 JSON 或 External Source NPZ 契约。

### 8.1 External Source NPZ

仍然使用：

```text
layer_0000_R
layer_0000_F
layer_0000_T
layer_0000_R_E
```

其中：

- `R`：树脂/沉积路径；
- `F`：纤维路径；
- `T`：非沉积空走路径；
- `_E`：对应沉积路径的逐点累计 E。

路径数组可以继续使用：

```text
[path_count, max_points_per_path, 3]   -> [x, y, z]
[path_count, max_points_per_path, 6]   -> [x, y, z, a, b, c]
```

第一版曲面模式建议继续输出 `[x,y,z]`，喷嘴保持竖直。后续加入姿态后才扩展到 `[x,y,z,a,b,c]`。

NPZ 的 `meta` 应新增曲面记录，但不改变原有键：

```json
{
  "surface": {
    "enabled": true,
    "format": "graded_surface_v1",
    "type": "double_sine_product",
    "amplitude_mm": 0.8,
    "wavelength_x_mm": 40.0,
    "wavelength_y_mm": 50.0,
    "alpha_range": [0.0, 1.0],
    "mapping_stage": "post_prusa"
  }
}
```

### 8.2 下游 Core 的约束

下游 Core 可以继续执行平滑、七阶参数化采样和机器人动作处理，但必须遵守：

- 不用 UI 的平面层高重新覆盖源路径 Z；
- 不把曲面 Z 当作普通层高重新量化成平面；
- 平滑和重采样要在 XYZ 曲线基础上执行；
- 如果使用姿态，姿态计算应在曲面法向检查之后进行；
- 现有 JSON、NPZ 字段和旧消费者保持兼容。

## 9. 可打印性检查

曲面路径输出前必须自动拒绝以下情况：

### 几何检查

- 曲面域超出 STL XY 投影；
- 外边界不闭合；
- 蜂窝拓扑在层间发生 XY 错位；
- 六边形单元被裁成无法闭合的半单元；
- 上层边界超出下层支撑范围；
- 顶部孔洞被连续填充封闭；
- 外侧出现不应存在的孔洞或断面。

### 层间检查

- 相邻层的局部高度差过大；
- 相邻沉积路径之间存在不可接受的垂直间隙；
- 曲率增加速度超过允许的层间沉积能力；
- 末端曲率突然跳变；
- 路径点间距过大导致曲面折线化。

### 工艺检查

- 局部坡度超过打印机和材料允许范围；
- 体积流量超过挤出系统上限；
- E 非有限、非单调或与路径点数不一致；
- 曲面路径的三维弧长与速度设置不匹配；
- 空走路径穿过已沉积曲面；
- 起始层无法在平面底部稳定附着。

## 10. 推荐实现阶段

### 阶段一：低幅值验证

- 只支持参数化双正弦曲面；
- 保持喷嘴竖直；
- 使用 Prusa 平面路径；
- 由后处理器修改所有沉积点的 Z；
- 关闭会封闭顶部蜂窝孔洞的顶层实心填充；
- 生成显式 `_E`；
- 先打印低幅值、少周期、少层数试件。

### 阶段二：渐变曲率和边界

- 增加 `alpha(z)` 平滑过渡；
- 增加 STL 投影域和闭合外边界检查；
- 处理不规则六边形边界和内部孔洞；
- 增加层间支撑、坡度、曲率和流量检查；
- 在 UI 中增加曲面 JSON 上传和参数预览。

### 阶段三：内核级集成

- 将曲面映射从 Prusa 后处理器移入统一路径层；
- 让 Prusa 输出阶段直接接受非平面路径或曲面约束；
- 保留 Prusa 的轮廓、填充、避障空走和 E 计算能力；
- 必要时加入曲面法向和 A/B/C 姿态；
- 增加曲面专用预览和仿真。

## 11. 最终推荐流程

```mermaid
flowchart TD
    A[STL 蜂窝模型] --> B[提取 XY 投影、蜂窝拓扑和闭合外边界]
    C[graded_surface_v1 JSON] --> D[生成双正弦目标高度场 H(x,y)]
    B --> E[Prusa 平面切片]
    E --> F[获得 XYZ 路径、累计 E、角色和空走顺序]
    D --> G[按层计算 alpha(z)]
    F --> H[曲面路径映射]
    G --> H
    H --> I[三维弧长与 E 重新分配]
    I --> J[边界、层间接触、坡度、孔洞和流量检查]
    J --> K[保持现有 External Source NPZ 输出]
    K --> L[下游 Core 平滑、采样和机器人执行]
```

最终应把曲面模式理解为：

```text
STL = 蜂窝拓扑与 XY 支撑边界
曲面 JSON = 最终高度场与曲率进度
Prusa = 平面路径、顺序和基础 E
曲面后处理 = XYZ 映射、E 修正和可打印性约束
NPZ = 保持现有接口的曲面轨迹
```
